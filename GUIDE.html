01

وش هو Hojas Studio

أداة مونتاج لمقاطع الكلام للكاميرا: تيك توك، ريلز، شورتس، إكس، لينكدإن. تعطي Claude الفيديو، يقص السكتات ويفرّغ كلامك ويكتب الكابشن العربي ويصمم المشاهد، وأنت تتابع شغله لحظة بلحظة بصفحة في المتصفح. ولما يخلص يتحول المقطع لتايم لاين تعدّل فيه أي شي بإيدك قبل التصدير.

Claude يمنتج

قص، تفريغ، كابشن، كروت شرح، صور ومقاطع توضيحية، مؤثرات وأصوات، على متطلبات منصتك.

أنت تتابع حي

صفحة تعرض المراحل ولقطات من الشغل أول بأول، من الكمبيوتر أو الجوال.

تعدّل على التايم لاين

تسحب، تقص، تغيّر الخط والألوان، تضيف عناصر، وكل تعديل يظهر فوراً.

كله على جهازك

الفيديو والصوت ووجهك ما ينرفعون لأي خدمة. والتوليد بالذكاء يصير من حساباتك أنت.

02

اللي تحتاجه

شي واحد لازم تجهّزه بنفسك: Claude Code مثبّت على جهازك ومسجّل دخول بحسابك. الطريقة الرسمية في صفحة Claude Code.

الباقي أدوات مجانية ومفتوحة المصدر. ما يحتاج تثبّتها بنفسك: Claude يفحص جهازك، ويقول لك وش الناقص وليش ومن وين ينزل وحجمه، وما يثبّت شي إلا بعد موافقتك.

الأداةليش نحتاجهاالمصدر والحجم
ffmpegيقص الفيديو ويركّب الصوت والصورة ويطلّع الملف النهائيffmpeg.org · 90 ميقا تقريباً
Python + whisperيفرّغ كلامك لنص بتوقيت كل كلمة عشان الكابشنمكتبة OpenAI المفتوحة · الموديل 1.4 قيقا مرة وحدة · يشتغل على جهازك
Node.jsيشغّل كروم بدون نافذة عشان يرسم الكابشن والكروت فريم فريمnodejs.org
Chrome أو Edgeمحرّك الرسم، نفس المتصفح اللي عندكما يتثبّت شي جديد لو عندك واحد

المساحة: الأداة نفسها 20 ميقا تقريباً، وموديل التفريغ 1.4 قيقا، وكل مشروع ياخذ حسب طول المقطع.

03

التثبيت خطوة بخطوة

الطريقة المنصوح فيها: البلقن. تثبّته مرة وحدة، وكل نسخة جديدة توصلك لحالها.

  1. ثبّت Claude Code وسجّل دخول

    من الصفحة الرسمية. لو هو عندك من قبل تخطّ هذي الخطوة.

  2. أضف متجر Hojas

    افتح Claude Code واكتب هذا الأمر واضغط Enter:

    /plugin marketplace add rakaga66/hojas-studio

  3. ثبّت البلقن

    /plugin install hojas-studio@hojas

  4. شغّل التحديث التلقائي (مرة وحدة)

    اكتب /plugin ثم اختر Marketplaces ثم hojas ثم Enable auto-update. من بعدها كل نسخة جديدة تنزل لحالها، والمكتبة تنتقل لها أول ما تفتح Claude Code. مشاريعك وإعداداتك محفوظة في ~/.hojas-studio والتحديث ما يلمسها.

  5. اقفل Claude Code وافتحه من جديد

    عشان يتعرّف على الأداة.

  6. خلّ Claude يفحص جهازكافحص أدوات Hojas Studio

    يقول لك وش موجود ووش ناقص (ffmpeg وPython مع Whisper وNode ومكتبة التصدير وكروم، وGit for Windows على ويندوز). وافق على اللي يحتاجه، وهو يثبّته ويتأكد إنه اشتغل.

  7. ابدأ أول مقطعمنتج هذا المقطع لتيك توك: C:\Users\you\Videos\clip.mp4
مهم: ثبّته من Claude Code على جهازك. من الطرفية (اكتب claude)، أو من تطبيق Claude بتبويب Code وجلسة على جهازك (مو سحابة)، وتضغط + ثم Add plugins. صفحة Plugins بموقع claude.ai أو المحادثة العادية ما تشغّله، لأن الأداة تشتغل على جهازك (الفيديو والتفريغ والاستوديو)، وتطلع لك رسالة «This plugin isn't for this environment».

طريقة ثانية: سكل بـ git

لو تبيها سكل عادي بدل البلقن، الصق هذا السطر في Claude Code:

Install this skill: git clone https://github.com/rakaga66/hojas-studio ~/.claude/skills/hojas-studio

هذي الطريقة ما تتحدّث لحالها: تحدّثها بنفسك (شوف «التحديث والإزالة» تحت).

من الطرفية بنفسك

ماك ولينكس:

git clone https://github.com/rakaga66/hojas-studio ~/.claude/skills/hojas-studio

ويندوز (PowerShell):

git clone https://github.com/rakaga66/hojas-studio "$HOME\.claude\skills\hojas-studio"

بدون git (الملف المضغوط)

نزّل الملف المضغوط من الموقع، فك الضغط في Documents، ودبل كلك على install.bat (ماك: bash install.sh). لو طلع تحذير ويندوز اضغط «More info» ثم «Run anyway». لازم تطلع رسالة Hojas Studio skill installed، ولا تنقل المجلد بعدها.

OpenCode؟ البلقن لـ Claude Code بس. OpenCode يقرأ مجلد ~/.claude/skills، فاستخدم طريقة السكل بـ git فوق. القص والتفريغ والكابشن والاستوديو تشتغل، وزر «نفّذ» يكتشفه لحاله (تجريبي). اللي يحتاج Claude in Chrome (التوليد من حساباتك والنشر) يشتغل مع Claude Code بس.
04

أول مقطع

  1. جهّز الفيديو

    صوّر مقطعك وحطه بأي مجلد بجهازك. أي صيغة من الجوال تمشي (mp4 أو mov).

  2. اطلب المونتاجمنتج هذا المقطع لتيك توك: C:\Users\…\Videos\clip.mp4

    تقدر تسحب الملف لنافذة Claude بدل ما تكتب مساره.

  3. تنفتح صفحة البث الحي

    بالمتصفح، وفيها مراحل الشغل: استلام، قص، تفريغ، كابشن، قص وزوم، مشاهد، رسم، نهائي.

  4. جاوب صفحة الأسئلة

    بعد التفريغ تتحول الصفحة لأسئلة عن منصتك وشكل المقطع. جاوب واضغط حفظ وأبدأ. Claude ما يسألك عن المونتاج بالمحادثة أبداً، كل شي هنا.

  5. تابع المونتاج

    كل مرحلة تظهر مع لقطات منها. تقدر تقفل الصفحة وترجع لها.

  6. عدّل على التايم لاين

    لما يخلص تتحول الصفحة لوحدها للاستوديو. غيّر اللي تبيه، أو اكتب ملاحظات على أي ثانية واطلب من Claude يطبّقها.

  7. صدّر

    زر تصدير فوق. الملف يطلع جاهز للنشر، وتقدر تنزّله على جوالك برمز QR.

الطابع والتلوين

الطابع يغيّر شكل المقطع كله بضغطة: ألوان الكروت والكابشن، الملمس، ونوع الانتقال. فيه 12 طابع، منها ملف سري، كينوت داكن، سينما صامتة، هولوقرام، فخامة ذهبية، سبورة، مشربية، وفانوس رمضان. وتلوين الفيديو يغيّر ألوان الفيديو بس (بشرة ناعمة، استوديو، دافي، سينمائي، أبيض وأسود…) والكتابة تبقى بألوانها.

كابشن وصوت أذكى

Claude يقسّم الكابشن على أنفاس كلامك بدل التقسيم الآلي، ويشيل الجمل اللي يخترعها التفريغ فوق السكوت مثل «اشتركوا في القناة». وفيه تمييزين جداد للكلمة المنطوقة: توهّج وقلم تظليل. وبلوحة الصوت: تحسين صوتك بستة أشكال (أوضح، أقل طنين، أنظف، أنعم، إذاعي، مكالمة)، والموسيقى الطويلة تنخفض لحالها وقت كلامك.

أسلوبين جاهزين

بصفحة الأسئلة اختر «أسلوب المونتاج»، أو قل لـClaude «منتجه بأسلوب الورق» أو «بأسلوب الدحيح».

ورق متحرك

شاشة ورق فاتح وكلامك ينكتب كلمة كلمة مع صوتك: سطر صغير، وكلمة كبيرة، وصندوق أسود للضربة. وتحتها كرت يوري اللي تتكلم عنه: طرفية تكتب الأمر، جوال، زر، تعليق، وحسابك مع زر «تابعني». وجهك يختفي وصوتك يكمل. كل شاشة تعدّلها من لوحة العنصر: كل سطر بسطر، ونجمة بأوله تكبّره، وعلامة > تحطه بصندوق أسود.

الدحيح

فوق رأس أسود فيه صورتك والعنوان، وتحته نافذة فيها مكتب ورق وراك (القص على جهازك). على المكتب كروت: ورقة مشبوكة بختم، بولارويد من لقطتك، رقم يعدّ وحوله دائرة يد، شطب واستبدال، فاتورة، ملفات، ساعة، أعمدة. والخلفية تتبدل بدائرة (ورق، كحلي، غرفتك، أخضر)، والكابشن برتقالي قصير تحت وجهك.

كرت الختام

مربع «كرت الختام» آخر تراك الفيديو. اضغطه تعدّل نصه: سطرين، دعوة، كلمة بارزة، سطر صغير، ونقاط. واختر خطه من القائمة (أي خط من خطوط الكابشن أو خط رفعته). اسحب طرفه اليمين تغيّر مدته، أو احذفه. ولو ما فيه ختام تضيفه من «الملفات».

08

التايم لاين والاختصارات

اسحب أي عنصر من نصه عشان تحركه، ومن طرفه عشان تطوّله أو تقصّره. تحريكه لفوق أو تحت ينقله بين صفوف الطبقات. لو سحبت قرب طرف التايم لاين يمشي لحاله.

المغناطيس يلصق العنصر على المؤشر وأطراف العناصر الثانية. لو تبي تحرك بحرية امسك Alt وأنت تسحب. الكابشن ماشي مع صوتك، فيتحرك بحدود السكتة اللي حوله بس. عشان تغيّر وقته اسحب أطرافه.

من الجوال

  1. اضغط زر «الجوال» فوق

    يطلع رمز QR.

  2. صوّر الرمز بكاميرا جوالك

    الجوال والكمبيوتر لازم على نفس الواي فاي. الرابط فيه رمز دخول خاص فيك.

  3. عدّل من الجوال

    المعاينة فوق، شريط تمرير وتشغيل، وخمس تبويبات: النص، الكابشن، إضافات، ملاحظات، تصدير.

المعاينة بالجوال بنص الدقة عشان تمشي خفيفة. التصدير ما يتأثر ويطلع بالدقة الكاملة.

إشعارات ومقاطعك على جوالك

بنفس نافذة «الجوال» اضغط فعّل الإشعارات. نزّل تطبيق ntfy المجاني (بدون حساب)، اضغط + واكتب اسم القناة اللي يطلع لك أو صوّر رمزه، واضغط «أرسل تجربة». بعدها Claude يكلّمك لحاله:

ينتظرك

لما تنفتح صفحة الأسئلة، أو يحتاج منك شي، يوصلك إشعار بدل ما يجلس ينتظر.

المقطع جاهز

أول ما يخلص التصدير يوصلك المقطع نفسه على الجوال (لين 15MB)، والأكبر منه يقول لك وينه.

قبل النشر

لو طلبت ينشر، يرسل لك إن المقطع جاهز وينتظر موافقتك قبل الضغطة الأخيرة.

التصدير والنشر والعميل

تصدير

زر «تصدير» فوق. يطلع ملف mp4 جاهز، والصوت مضبوط على مستوى المنصات.

على الجوال

بعد التصدير اضغط «على الجوال» وصوّر الرمز، فيتحمّل الملف على جوالك مباشرة.

حزمة النشر

من «المشروع»: المقطع، ملفات ترجمة SRT عربي وإنجليزي، نص كلامك، نص المنشور، وحقوق الصور، بملف zip واحد.

مراجعة العميل

رابط برمز خاص. العميل يعلّق على أي ثانية ويرسم ويعتمد، وتعليقاته ما تتطبّق إلا لو حوّلتها لملاحظة.

النشر على تيك توك

بعد التصدير قل له: انشره على تيك توك أو جدوله على تيك توك بكرة الساعة 8 المغرب. Claude يفتح TikTok Studio من متصفحك وبحسابك المسجّل، يرفع المقطع ويحط الوصف من نص المنشور، ويوقف قبل زر النشر ويسألك. ما يحتاج أي مفتاح، وما يكتب كلمة سرك أبداً. الضغطة الأخيرة لك عشان أي غلطة ما تنزل للعامة، وعشان تيك توك ما يقيّد حسابك.

يتعلّم أسلوبك

كل تعديل تسويه على مونتاج Claude (الخط، الألوان، كرت الختام، الطبقات اللي تحذفها، الكلمات اللي تصحّحها بالتفريغ) ينحفظ لما تصدّر. المقطع الجاي يبدأ قريب من ذوقك، والتصحيح اللي تكرره مرتين يتطبّق لحاله. اسأله وش تعرف عن أسلوبي؟ يعرضه لك.

مشاكل وحلولها

Claude ما يعرف الأداة
تأكد إنك شغّلت install.bat وطلعت رسالة النجاح، ثم اقفل Claude Code وافتحه.
يقول «ما لقيت مجلد engine»
ملفات الأداة ناقصة أو المجلد انتقل. نزّلها من جديد وشغّل install.bat.
شاشة سوداء بالمعاينة
حدّث الصفحة. لو استمرت قل لـ Claude: «المعاينة سوداء عند الثانية كذا».
الخلفية ما تغيّرت أو النص ما مر وراي
فصل الشخص لسه يشتغل، انتظر ثواني. النص خلفك يحتاج الفيديو ملء الشاشة.
الجوال ما يفتح الرابط
نفس الواي فاي، وجدار الحماية بالكمبيوتر يسمح للبورت 8800.
الجوال يعلّق أو بلا صوت
حدّث الصفحة مرة. المعاينة هناك أخف، والتصدير ما يتأثر.
الخط ما تغيّر
خطوط Google تحتاج نت. بدون نت ارفع ملف الخط من «الملفات».
التجميع يفشل على ويندوز
لازم Git for Windows. اطلب من Claude «افحص أدوات Hojas Studio».
«This plugin isn't for this environment»
ثبّته من Claude Code على جهازك، مو من صفحة Plugins بموقع claude.ai. شوف «التثبيت خطوة بخطوة».
«OAuth session expired» أو «Failed to authenticate»
تسجيل دخولك بـ Claude Code انتهى. افتح الطرفية واكتب claude ثم /login، وبعدها اضغط «أعد» على المقطع.
«Access is denied [WinError 5]»
انحل بنسخة 4.33. حدّث البلقن (افتح جلسة جديدة، أو قل «حدّث بلقن Hojas»).
«ما لقيت مكتبة التصدير»
قل لـ Claude «ثبّت مكتبة التصدير». يستأذنك وينزّلها مرة وحدة (8 ميقا) وتبقى مع كل تحديث.
الصوت بالمقطع النهائي أوطى من باقي المقاطع
كانت معايرة الصوت تفشل على ويندوز، وانحلت بنسخة 4.35. حدّث وصدّر من جديد.
أبي أحذف مقطع
من المكتبة افتح المقطع واضغط «احذف المقطع». ينتقل لمجلد .trash بمجلد مشاريعك، وترجّعه من هناك لو غيّرت رأيك.
ChatGPT أو Gemini طلب تسجيل دخول
سجّل دخولك بمتصفحك. Claude ما يتجاوز تسجيل الدخول ولا حدود حسابك، والطلب ينتظرك.

التحديث والإزالة

التحديث

البلقن: لو شغّلت التحديث التلقائي ما تسوي شي، النسخة الجديدة توصلك لحالها والمكتبة تنتقل لها أول ما تفتح Claude Code (لو فيه تصدير شغّال، تنتظر للجلسة الجاية). تبي تحدّث الحين؟ اكتب /plugin marketplace update hojas، وبعدها اقفل Claude Code وافتحه.

سكل بـ git: قل لـ Claude حدّث Hojas Studio (يشغّل python hs.py update).

الملف المضغوط: نزّل الجديد وفك ضغطه مكان القديم وشغّل install.bat مرة ثانية.

بكل الطرق مشاريعك ما تتأثر، وتلقى وش الجديد في صفحة التحديثات.

الإزالة

البلقن: اكتب في Claude Code /plugin uninstall hojas-studio@hojas.

سكل بـ git أو الملف المضغوط: احذف مجلد .claude\skills\hojas-studio من مجلد المستخدم (ولو ثبّتها بالملف المضغوط احذف مجلدها بعد).

أصواتك وإعداداتك ومشاريعك في .hojas-studio بمجلد المستخدم، احذفه لو تبي تمسحها بعد.
